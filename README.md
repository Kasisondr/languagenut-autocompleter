# Lume

### A fast, open-source Languagenut autocompleter

**Lume** is an open-source autocompleter built for Languagenut. It is designed to support a wide range of Languagenut activities while remaining fast, lightweight, and easy to use.

> **Status:** Actively developed  
> **Platform:** Languagenut  
> **Source:** Open source

---

## Features

### Wide Game Mode Support

Lume supports **most, if not all, commonly encountered Languagenut game modes**.

Instead of being designed around a single activity, Lume attempts to recognise different game types and handle them automatically.

Support may vary if Languagenut introduces new activities or changes existing ones.

### Fast

Lume is designed with speed in mind.

The script avoids unnecessary delays and attempts to process supported activities as efficiently as possible.

### Fake Time Support

Lume includes configurable **fake time** functionality.

This can simulate a longer activity duration rather than simply recording the real execution time.

### Lightweight

The project focuses on doing one job without unnecessary extras.

Lume aims to remain:

- Fast
- Lightweight
- Simple to use
- Easy to modify
- Easy to understand

### Open Source

Lume is completely open source.

You can inspect the code, learn how it works, modify it, improve it, or contribute fixes and additional game support.

No mystery binaries. No hidden code.

---

## Supported Activities

Lume aims to work across a large portion of the Languagenut activity system.

Depending on the current version, this may include activities involving:

- Vocabulary
- Reading
- Listening
- Sentence building
- Multiple-choice questions
- Matching activities
- Word-based activities
- Interactive game modes
- Other supported Languagenut exercises

Because Languagenut can update its website at any time, individual activities may occasionally require fixes.

If you find an unsupported activity, consider opening an issue with information about the game mode.

---

## Performance

Lume has been designed to minimise unnecessary processing and delays.

The goal is simple:

**Detect → Process → Complete**

Rather than relying on heavy frameworks or unnecessary dependencies, Lume keeps the automation process as lightweight as possible.

---

## Fake Time

Some activities record how long they take to complete.

Lume includes fake-time functionality that can simulate activity duration when testing how timing behaviour works.

The exact behaviour depends on the version of Lume and the Languagenut activity being used.

## Updating

Languagenut may change its interface, game logic, API behaviour, or activity structure without notice.

As a result, an update to Languagenut can occasionally break part of Lume.

If something stops working:

1. Make sure you are running the latest version of Lume.
2. Check the repository for existing issues.
3. Confirm whether the problem affects one game mode or all activities.
4. Open a new issue if the problem has not already been reported.

When reporting a bug, include as much useful information as possible.
